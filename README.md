# Club Balonmano Almoradí - Web oficial

Web del **Club Balonmano Almoradí** (Almoradí, Alicante), equipo de balonmano que compite en **Primera Nacional**.

## Secciones
- Inicio y presentación del club
- Historia desde 1956
- Cronología de hitos
- Premios y reconocimientos (Mejor Club Deportivo de la Provincia 1983)
- El club y la cantera
- Colaboración oficial con **Joma**
- Contacto

## Tecnología
HTML5 + CSS3 + JavaScript vanilla, sin dependencias. Logos en SVG.

[Ver la web publicada](https://hachimiamin381-prog.github.io/balonmano-almoradi/)
